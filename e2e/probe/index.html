第一步：上传采集报告

采集完成后会自动上传。标签可以改（例如 win11-rtx3060），改后点“上传报告”再传一次，下次刷新也会沿用。

第二步：上传 Windows 字体（只需做一次）

在这台 Windows 上打开 PowerShell，执行下面的命令，把系统字体打包到桌面：

$d = "$env:TEMP\winfonts"; robocopy "$env:WINDIR\Fonts" $d *.ttf *.ttc *.otf /R:0 /W:0 /NFL /NDL /NJH /NJS | Out-Null; Compress-Archive -Path "$d\*" -DestinationPath "$env:USERPROFILE\Desktop\winfonts.zip" -Force

完成后在下面选择桌面上的 winfonts.zip 上传（文件较大，请等待进度完成）。
